# Was ist ein IoT-Element?

Ein **IoT-Element** ist ein Gerät, das mit Sensoren Informationen aus
seiner Umgebung erfassen oder mit Aktoren etwas steuern kann. Die Daten
können über ein Netzwerk oder das Internet an andere Geräte oder Systeme
übertragen werden.

Ein Sensor kann zum Beispiel **Temperatur, Feuchtigkeit, Bewegung oder
Wasser** erkennen. Ein Aktor kann darauf reagieren, zum Beispiel eine
LED einschalten, einen Alarm auslösen oder ein Relais schalten.

## Mein Beispiel: Wassersensor

Als praktisches Beispiel habe ich selbst einen **Wassersensor mit einem
Arduino-Kit aufgebaut und in Java programmiert**. Der Sensor erkennt,
wenn er mit Wasser in Kontakt kommt. Das Programm verarbeitet
anschließend die gemessenen Werte und kann darauf reagieren, zum
Beispiel mit einer Warnung.

Wassersensoren werden auch in **Rechenzentren** eingesetzt. Dort können
sie beispielsweise in der Nähe von Klimaanlagen, Kühlanlagen oder
Wasserleitungen platziert werden. Wenn ein Wasserleck entsteht, kann es
früh erkannt und ein Alarm ausgelöst werden. Dadurch können Schäden an
Servern und anderen IT-Geräten verhindert werden.

## Kurz erklärt

**Sensor → misst Wasser → Arduino verarbeitet Daten → Programm reagiert
→ z. B. Alarm**
